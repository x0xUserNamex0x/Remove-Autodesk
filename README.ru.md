# Remove-Autodesk

[English version](README.md)

PowerShell-скрипт для полного удаления программного обеспечения Autodesk с компьютера под Windows, чтобы можно было установить продукты Autodesk начисто, без конфликтов версий.

Скрипт удаляет продукты и компоненты лицензирования, а затем подчищает хвосты: службы, задачи планировщика, правила брандмауэра, папки во всех профилях пользователей, ключи реестра (включая выгруженные пользовательские кусты), переменные окружения и записи в PATH.

## Возможности

- Тихое удаление всех продуктов Autodesk (MSI и ODIS, версии 2020+)
- Правильный порядок: сначала продукты, затем Licensing, Single Sign On, Desktop App, Identity Manager, Genuine Service и другие общие компоненты (два прохода)
- Остановка процессов Autodesk, удаление служб, задач планировщика и правил брандмауэра
- Удаление папок в `Program Files`, `Common Files\Autodesk Shared`, `ProgramData`, `Public` и во всех профилях (`AppData\Local`, `Roaming`, `LocalLow`, `Identities`)
- Чистка реестра: `HKLM\SOFTWARE\Autodesk`, «осиротевшие» записи Uninstall, ProgID, App Paths, ключи Run и все пользовательские кусты (загруженные и выгруженные через `NTUSER.DAT`)
- Удаление переменных `ADSK_*`, `ADSKFLEX_LICENSE_FILE`, `AUTODESK_*` и записей Autodesk из системного PATH
- Захват владения «упрямыми» файлами и повторная попытка удаления
- Режим `-DryRun`, который ничего не меняет
- Полный лог и итоговый отчёт об оставшихся элементах

## Требования

- Windows 10 / 11 или Windows Server 2016+
- PowerShell 5.1 или новее
- Права локального администратора

## Использование

1. Закройте все программы Autodesk и сохраните данные.
2. Откройте PowerShell от имени администратора.
3. Сначала запустите пробный режим, чтобы увидеть, что будет удалено:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\Remove-Autodesk.ps1 -DryRun
   ```

4. Запустите реальную очистку:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\Remove-Autodesk.ps1
   ```

5. Перезагрузите компьютер.
6. Если в итоговом отчёте есть заблокированные пути или остатки, запустите скрипт ещё раз после перезагрузки.

Лог сохраняется в `C:\Temp\Autodesk-Cleanup_<ИМЯ_ПК>_<дата>.log`.

## Параметры

| Параметр | Описание |
|---|---|
| `-DryRun` | Показать, что будет сделано, ничего не меняя |
| `-SkipUninstall` | Пропустить удаление продуктов, только чистить хвосты |
| `-RemoveUserDocuments` | Дополнительно удалить `Documents\Autodesk` во всех профилях (там могут быть проекты и шаблоны пользователей) |
| `-RemoveFlexNet` | Дополнительно удалить FlexNet Licensing Service и `Macrovision Shared` (используются другими вендорами, по умолчанию отключено) |

## Что делается вручную

Часть действий безопаснее или удобнее выполнить руками:

- **Продукты, которые не удалились** (перечислены в итоговом отчёте): используйте официальный Autodesk Uninstall Tool или Microsoft Program Install and Uninstall troubleshooter. Скрипт намеренно не трогает «осиротевшие» записи Windows Installer в `HKLM\SOFTWARE\Classes\Installer\Products`.
- **Network License Manager** на сервере лицензий: удаляется отдельно.
- **Переменная `LM_LICENSE_FILE`**: скрипт только предупреждает о ней, так как она может принадлежать другим вендорам.
- **Ярлыки**, закреплённые вручную на рабочем столе или в панели задач, удалите самостоятельно.
- **Лицензии в Autodesk Account**: перед очисткой машины освободите назначения пользователей, чтобы лицензии не остались привязанными к ней.

## Проверка результата

После перезагрузки убедитесь, что:

- в «Программах и компонентах» нет записей Autodesk;
- в `services.msc` нет служб Autodesk (включая `AdskLicensingService`);
- не существуют папки `C:\Program Files\Autodesk`, `C:\ProgramData\Autodesk` и `C:\Program Files (x86)\Common Files\Autodesk Shared`;
- не существуют ключи `HKLM\SOFTWARE\Autodesk` и `HKCU\Software\Autodesk`.

## Массовое применение

Разместите скрипт на сетевой шаре и запускайте через GPO (скрипт запуска компьютера), `Invoke-Command` или PsExec. Сначала проверьте на пилотной группе из 2–3 машин с параметром `-DryRun`.

## Предупреждение

Скрипт безвозвратно удаляет данные, включая настройки Autodesk, кэши, данные лицензирования и (с `-RemoveUserDocuments`) пользовательские файлы. Он предназначен для чистой переустановки. Используйте на свой риск, сначала проверьте на нерабочей машине и сделайте резервные копии всего необходимого.
